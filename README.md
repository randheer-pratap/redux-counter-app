# Redux Counter App

A simple React application built for learning state management using Redux Toolkit.

## 🚀 Features

- Increment counter
- Decrement counter
- Reset counter
- Maximum limit handling
- Minimum limit handling

## 🛠️ Tech Stack

- React
- Redux
- @reduxjs/toolkit
- React-Redux

## 📁 Project Purpose

This project is created to understand:

- How Redux works internally
- State management using Redux Toolkit
- Store, slices, and reducers
- Connecting React components with Redux

## ▶️ Getting Started

1. Clone the repository

```bash
git clone https://github.com/your-username/redux-counter-app.git

2. Navigate to project folder
    cd redux-counter-app

3. Install dependencies
    npm install

4. Start the app
    npm start
```
